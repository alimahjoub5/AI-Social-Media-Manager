# AI Social Media Manager

This project is a practice UiPath automation designed to manage social media content creation. It leverages AI to generate posts based on current trends.

## Workflows

The automation is composed of the following workflows:

*   **WF01_Get_Trends.xaml**: Identifies trending topics or keywords.
*   **WF02_Generate_Content.xaml**: Uses the identified trends to generate text-based social media content.
*   **WF03_GenerateImages.xaml**: Creates relevant images to accompany the generated content.

This project serves as a demonstration of integrating UiPath with AI for content automation tasks.
